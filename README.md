# BIOIN401
## SangerAI
My BIOIN401 project: Creating a virtual avatar of Fred Sanger!

## Installation
1. Clone the repository:
    ```sh
    git clone https://github.com/hannahzam/BIOIN401.git
    ```
2. Navigate to the project directory:
    ```sh
    cd BIOIN401
    ```
3. Create virtual environment and activate it:
    ```sh
    python -m venv <environment_name>
    ```
4. After activating virtual environment, install requirements.txt
   ```sh
    pip install -r requirements.txt
    ```
6. Run sangerAI.py
   ```sh
    python sangerAI.py
    ```
